# Use SDK to Automate Static Web Hosting

## 🎯 Purpose

The purpose of this project is to automate static website hosting on AWS using Python scripts and the boto3 SDK.

This project demonstrates how to:

* Create and configure an Amazon S3 bucket
* Upload website files automatically
* Enable static website hosting
* Manage AWS resources programmatically using Python

The automation reduces manual effort and enables faster deployment of static websites.

## 🧰 AWS Services Used

* **Amazon S3** – Used for storing and hosting static website files.
* **boto3** – Python SDK used to automate AWS resource creation and file uploads programmatically.
